# 形迹 · 微信小程序

对齐 Web「形迹」研究终端的模块与首页大屏逻辑，并针对手机端改版。

## 原 Web 首页逻辑（已复刻）

1. **股票搜索**：顶栏输入代码/名称 → 联想 → 进入行情  
2. **缓存状态**：上次更新 / 已缓存 / 提醒数  
3. **缓存大屏**（与提醒分页签，避免重复）  
   - 查看方式：`按行业` | `按概念` | `倾向/价位`  
   - 横向筛选 chips（涨停/偏多/价位等）  
   - 行业/概念：**下拉单组显示**（同一区域切换，不整页堆叠多行业）  
   - 股票卡片：代码、名称、涨跌、行业/倾向标签、☆自选  
4. **买卖提醒**：独立页签，偏多/偏空再分段，含理由摘要  

## 手机端注意

- 后端：`uvicorn server:app --host 0.0.0.0 --port 8765`  
- 真机 API：`http://192.168.3.202:8765`（更多 → 连接设置）  
- 开发者工具勾选「不校验合法域名」
